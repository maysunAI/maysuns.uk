# VIDEO_WORKFLOW.md

# Goal

目标：

每开发完成一个新功能，

自动生成适合传播的视频内容。

视频不是为了展示技术，

而是为了吸引用户。

----------------------------------------

# Workflow

Feature Finished

↓

分析功能

↓

提炼用户痛点

↓

一句话卖点

↓

生成视频脚本

↓

生成图片 Prompt

↓

生成图片

↓

生成动画

↓

生成配音

↓

生成字幕

↓

自动剪辑

↓

输出 MP4

↓

生成发布文案

↓

发布建议

----------------------------------------

# Video Length

默认：

30~60 秒

如果教程：

2~5 分钟

如果完整介绍：

5~10 分钟

----------------------------------------

# Video Structure

第一秒：

提出问题

例如：

"每天都找不到之前保存的 Prompt？"

3 秒

展示产品

10 秒

展示解决过程

10 秒

展示效果

最后：

一句 CTA

例如：

立即体验

GitHub Star

免费下载

查看更多

----------------------------------------

# Script Rule

不要介绍功能。

介绍：

用户得到什么。

例如：

不要：

新增 Prompt 管理。

而是：

一分钟找到以前保存的 Prompt。

----------------------------------------

# Image Rule

先生成 Prompt。

Prompt 保存到：

prompts/images/

方便以后重复生成。

----------------------------------------

# Voice Rule

支持：

中文

英文

日文

生成字幕：

SRT

VTT

TXT

----------------------------------------

# Editing

自动完成：

字幕

背景音乐

Logo

片头

片尾

横屏

竖屏

Square

----------------------------------------

# Export

默认输出：

videos/

其中包括：

youtube/

xiaohongshu/

douyin/

twitter/

每个平台生成不同尺寸。

----------------------------------------

# Quality Check

输出之前检查：

字幕是否正确

图片是否清晰

Logo 是否存在

是否存在敏感内容

是否存在明显错误

如果存在，

自动重新生成。

----------------------------------------

# Publishing Suggestion

每个视频生成：

标题

简介

标签

封面文字

关键词

SEO 描述

方便直接发布。
