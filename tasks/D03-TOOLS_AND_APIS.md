# TOOLS_AND_APIS.md

# Principle

Cloud Code：

负责：

思考

规划

生成 Prompt

编写代码

调用 API

自动组织流程

不要负责：

复杂图片生成

复杂视频生成

真人配音

这些交给专业 AI。

----------------------------------------

# Image

推荐：

OpenAI Images

优点：

API 简单

质量稳定

适合产品截图

----------------------------------------

如果需要：

漫画

海报

宣传图

可选择：

Midjourney

----------------------------------------

# Video

推荐：

Google Veo

适合：

宣传片

演示视频

----------------------------------------

第二选择：

Runway

适合：

图片变视频

----------------------------------------

第三选择：

Kling

适合：

中文内容

短视频

----------------------------------------

# Voice

推荐：

ElevenLabs

支持：

API

多语言

自然配音

----------------------------------------

# Subtitle

Whisper

自动生成字幕

支持多语言

----------------------------------------

# Editing

FFmpeg

自动：

拼接

压缩

加字幕

加 Logo

裁剪尺寸

----------------------------------------

# OCR

需要识别图片文字：

优先 OCR

不要人工输入。

----------------------------------------

# Automation

Cloud Code 负责：

统一调度。

例如：

生成 Prompt

↓

调用图片 API

↓

等待结果

↓

调用视频 API

↓

等待结果

↓

调用配音

↓

生成字幕

↓

FFmpeg 合成

↓

输出最终视频。

----------------------------------------

# Cost Strategy

优先：

已有会员

其次：

API 按量付费

最后：

新增订阅

不要同时推荐多个重复功能的平台。

----------------------------------------

# Continuous Improvement

每个月检查：

是否有新的 AI 工具

是否有更低成本方案

是否有更好的 API

主动提出升级建议。
